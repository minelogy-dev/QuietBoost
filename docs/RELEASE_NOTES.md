Windows 10/11 x64 原生音频增益工具，由 minelogy-dev 维护，OpenAI Codex 作为 AI 开发协作者参与。

### 本版新增：课堂侧边音量条与登录自启

- 平时只留半透明的“音量”窄条，点击后展开滑块，鼠标移出约 1.2 秒自动收起；窗口不会主动抢走课件焦点。
- 勾选主窗口的“开机自启”一次，以后登录时只显示侧边条、不弹主窗口，设备延迟就绪时自动重试连接。
- 使用当前用户启动文件夹和固定的本地 EXE 副本，无需管理员权限；删除下载文件后仍可自启，取消勾选即可关闭。
- 可拖动换边，保留悬浮窗模式、恢复 100%、设置入口及界面间增益同步。
- 每次启动仍为 100% 增益并开启自动恢复，不保存高增益或临时关闭保护的状态。

### 下载与使用

- 下载 **QuietBoost.exe** 直接运行。主程序使用静态 MSVC 运行库，无需 .NET 或另装 VC++ 运行库。
- **SHA256SUMS.txt** 提供 EXE 的 SHA-256 校验值。
- 首次使用点击“安装虚拟设备”，完成官方 VB-CABLE 安装和所要求的重启；驱动安装需要管理员授权。驱动的原始文件、许可及官方签名均保留在 EXE 内。
- 主程序本身尚未签名，Windows 可能提示未知发布者。

### 功能

- 虚拟音频输出 → 增益及限幅 → 实际输出。默认界面上限 2000%，配置可提高。
- 约五秒无有效音频后平滑恢复 100%。关闭保护须二次确认，且只对本次进程有效。
- 自动切换普通播放的默认设备，正式退出时恢复；保留用户运行期间手动选择的新设备。
- 不修改 Windows 系统音量、应用音量或静音设置。

### 验证范围与预览版限制

GitHub Actions 构建 Debug 和 Release，运行 76 项核心、配置、设备恢复、原生窗口及自启注册检查，并验证 Release 的系统 DLL 依赖、内置驱动 SHA-256 和官方安装程序 Authenticode 签名。自启测试只写入隔离的临时启动目录，不注册到测试机器的真实自启文件夹。只有全部成功才自动发布。

**完整非静音的“虚拟设备 → 增益 → 实际设备”链路及跨设备恢复尚待实机验收，本版继续标为预览版。** 本地已完成的静音 WASAPI 探测和模拟设备恢复检查不能替代此验收。CI 不安装驱动、不播放音频、不切换设备。详细记录见仓库 VALIDATION.md。
