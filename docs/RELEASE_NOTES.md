Windows 10/11 x64 原生音频增益工具，由 minelogy-dev 维护，OpenAI Codex 作为 AI 开发协作者参与。

### 下载与使用

- 下载 **QuietBoost.exe** 直接运行。主程序使用静态 MSVC 运行库，无需 .NET 或另装 VC++ 运行库。
- **SHA256SUMS.txt** 提供 EXE 的 SHA-256 校验值。
- 首次使用点击“安装虚拟设备”，完成官方 VB-CABLE 安装和所要求的重启；驱动安装需要管理员授权。驱动的原始文件、许可及官方签名均保留在 EXE 内。
- 主程序本身尚未签名，Windows 可能提示未知发布者。

### 功能

- 虚拟音频输出 → 增益及限幅 → 实际输出。默认界面上限 2000%，配置可提高。
- 约五秒无有效音频后平滑恢复 100%。关闭保护须二次确认，且只对本次进程有效。
- 自动切换普通播放的默认设备，正式退出时恢复；保留用户运行期间手动选择的新设备。
- 不修改 Windows 系统音量、应用音量或静音设置。

### 验证范围与预览版限制

GitHub Actions 构建 Debug 和 Release，运行 45 项核心、配置及设备恢复检查，并验证 Release 的系统 DLL 依赖、内置驱动 SHA-256 和官方安装程序 Authenticode 签名。只有全部成功才自动发布。

**完整非静音的“虚拟设备 → 增益 → 实际设备”链路及跨设备恢复尚待实机验收，因此首发标为预览版。** 本地已完成的静音 WASAPI 探测和模拟设备恢复检查不能替代此验收。CI 不安装驱动、不播放音频、不切换设备。详细记录见仓库 VALIDATION.md。

VB-CABLE 为 VB-Audio / Vincent Burel 的 donationware，使用须遵循其许可。主项目尚未指定开源许可证。
